# s11: the 1M profile (`PROFILE=long`) on the MLX 4-bit checkpoint, two ranks, vision on

Two boots on 2026-10-07, both TP=2, serial engine (`PARALLEL=1`), int8 KV, `VISION=1`, `CONTEXT=1048576` through the YaRN profile folder (patch part 7, pin `6868816a`).

1. `mlx1m.log`: the first probe. The snapshot served through a development launcher on port 8889 (the same image bytes, built from the sibling recipe's Dockerfile with the same patch; the profile folder built by hand the way `run.sh ensure_long_profile` builds it). Short prompts drafted against `"draft": false`, the frozen ruler at one user, the vision probe, needles at 8k / 300k / 1M with a 200-token follow-up on the same document, and the 1M needle at 10% depth.
2. The recipe's own path, `PROFILE=long VISION=1 ./run.sh` on port 8888 with the new default image (`tf-qwen38-flashnext:0.6.6`, patch `flashnext-0.6.6.patch`): `run-long.log` (the boot), `startup-long.txt` / `startup-long-rank1.txt` (the engine's startup lines on each rank: window, rotary, memory), `cmp-long.txt` + `texts-long.json` (drafted against undrafted), `bench-long-c1.out` (frozen ruler), `visioncheck-long.txt`, `needle-long.txt` (8k and 300k with follow-ups, 1M at mid-depth), `done-lines-long.txt` (the engine's per-request lines: prompt tokens, prefill time, decode tok/s), `stop-long.log`, `chain.log` and `chain.sh.txt` (the whole sequence as it ran, including a first production restart that failed with the worker's `ibv_reg_mr_iova2: Cannot allocate memory` five seconds after the stop and succeeded on systemd's retry; that is what `stop.sh`'s `stopped_at` stamp and `run.sh settle_after_stop` now prevent).
3. The plain profile rechecked on the new image, right after: `ref-cmp-old-image.txt` / `ref-texts-old-image.json` / `ref-visioncheck-old-image.txt` were taken on the previous image (`flashnext-tools-0.6.6.patch`, `PROFILE=concurrent VISION=1`) before the swap; `cmp-prod-new-image.txt` / `texts-prod-new-image.json` / `visioncheck-prod-new-image.txt` / `bench-prod-new-image-c1.out` on the new image, same profile. The reply shas are what to compare.

`tools/needle.py` generates the document (a fixed seed per length and depth), plants "The secret code for the blue door is 7-4-1-9-2." at the depth, asks for the digits, and with `FOLLOWUP=1` asks a 150-word question on the same document; `tools/cmp_drafts.py` is the drafted-against-undrafted check.
